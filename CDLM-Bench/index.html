Likelihood matters. So does its meaning.

Three perplexities.
Three different questions.

Keep the model’s probability, a computable bound, and an external judge’s score distinct.

EXACT PPL

What probability does the model assign to real text?

Autoregressive token conditionals give a directly computable discrete likelihood under a specified tokenizer and scoring convention.

PPLθ = exp(𝓛θ)
BOUND PPL

How large is an upper bound on the model’s NLL?

A latent CDLM’s bound includes posterior mismatch. Its ranking combines model fit with the tightness of the inference reference.

𝓤r = 𝓛θ + 𝓖r𝓖r ≥ 0
GEN PPL

How predictable are generated outputs to a judge?

An external language model scores generated texts. Concentrating on easy texts can improve this score while reducing output diversity.

GenPPL = exp(CEjudge)
↗

A useful comparison has a direction.

Under matched scoring, a valid CDLM NLL bound below exact AR NLL certifies a likelihood improvement. A bound above AR NLL does not establish the reverse ranking. A reference-scale optimum also does not certify a small total gap.

Experimental protocol and how to read the scores +

OWT validation pilot: 128-token source windows, 512 outputs per set, and 3 folds from one available shard. Gen PPL is scored by GPT-2 Large. Hrow is mean within-text unigram entropy.

“MMD display” is sign(MMD²)√|MMD²|, using BF16 mean-pooled GPT-2 Large features and a reference-median RBF bandwidth. MAUVE uses FP32 last-token features, 51 clusters, and 3 clustering seeds per fold. Their default pipelines differ; the table does not isolate the discrepancy formula.

± denotes fold standard deviation, not a confidence interval. Controlled repetitions are descriptive stress tests. The selected single text minimizes judge NLL subject to entropy at least the control mean; it was not selected by human ratings. Feature-neighbor selection uses the same mean-feature space and is a directed diagnostic.

The scoring protocol uses independent kernel calibration for statistical inference and keeps it distinct from these historical default-pipeline results. No model leaderboard is implied by constructed output sets.

01 / COLLAPSE

Sample quality is only part of the story.

Within-text entropy can stay high when every output is identical. Measure variation across outputs as well as inside each text.

02 / SENSITIVITY

The representation changes what you see.

Mean and last-token features respond differently to edit location. Formatting can move a score more than structural corruption.

03 / CALIBRATION

A small distance has limits.

Rare errors can be diluted in global measurements. Pair the distribution score with explicit event rates, coverage, and real-versus-real controls.
